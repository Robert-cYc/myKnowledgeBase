# 網頁版 Knowledge Base

一個簡單易用的網頁知識庫應用程式，支援新增、移除、修改、搜尋功能，並可匯入 PDF 和 Markdown 檔案。

## 功能特色

- 📝 **新增/編輯/刪除** 知識項目
- 🔍 **全文搜尋** 和 **標籤篩選**
- 📄 **PDF 匯入** - 自動提取文字內容
- 📘 **Markdown 匯入** - 自動提取標題和內容
- 💾 **自動儲存** - 使用瀏覽器 localStorage 儲存資料
- 📱 **響應式設計** - 支援各種裝置

## 技術架構

- React + TypeScript
- Vite 建置工具
- Tailwind CSS 樣式
- Zustand 狀態管理
- PDF.js 解析 PDF
- Marked 解析 Markdown

## 開始使用

1. 安裝依賴套件
```bash
npm install
```

2. 啟動開發伺服器
```bash
npm run dev
```

3. 建置生產版本
```bash
npm run build
```

## 使用說明

### 新增知識項目
1. 點擊「新增項目」按鈕
2. 填寫標題、內容和標籤
3. 點擊「新增」保存

### 匯入檔案
1. 點擊「點擊選擇檔案」按鈕
2. 選擇 PDF 或 .md/.markdown 檔案
3. 系統會自動解析並建立知識項目

### 搜尋與篩選
- 使用搜尋框輸入關鍵字
- 點擊標籤按鈕進行篩選
- 點擊清除按鈕移除篩選

### 編輯/刪除
- 在知識項目列表中點擊編輯或刪除按鈕
