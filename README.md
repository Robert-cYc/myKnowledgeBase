# 網頁版 Knowledge Base

一個簡單易用的網頁知識庫應用程式，支援新增、移除、修改、搜尋功能，並可匯入 PDF、Markdown、圖片、影片和文檔檔案。

## 功能特色

- 📝 **新增/編輯/刪除** 知識項目（支援備註欄位）
- 🔍 **全文搜尋** - 搜尋標題、內容和備註
- 🏷️ **標籤篩選** - 點擊標籤進行篩選
- 🏷️ **標籤管理** - 重新命名、合併、刪除標籤
- 📁 **分類管理** - 為項目分配分類並進行管理
- 🤖 **自動分類** - 依據內容關鍵字自動添加標籤
- 📄 **PDF 匯入** - 自動提取文字內容並支援多頁 PDF 檢視
- 📘 **Markdown 匯入** - 自動提取標題和內容
- 🖼️ **圖片匯入** - 直接匯入圖片檔案
- 🎬 **影片匯入** - 匯入 MP4 等影片格式並內建播放器
- 📎 **文檔匯入** - 支援 TXT、Word、Excel、PowerPoint 格式
- 💾 **資料匯出/匯入** - JSON 格式匯出，支援合併或替換模式
- 📊 **多種檢視模式** - 圖示、並排、詳細資料
- 📱 **響應式設計** - 支援各種裝置
- 🔒 **IndexedDB 儲存** - 瀏覽器本地資料庫儲存，容量更大

## 技術架構

- React + TypeScript
- Vite 建置工具
- Tailwind CSS 樣式
- Zustand 狀態管理
- IndexedDB 本地儲存（自動遷移自 localStorage）
- PDF.js 解析 PDF
- Mammoth 解析 Word/PowerPoint
- SheetJS 解析 Excel
- Marked 解析 Markdown

## 開始使用

1. 安裝依賴套件
```bash
npm install
```

2. 啟動開發伺服器
```bash
npm run dev
```

3. 建置生產版本
```bash
npm run build
```

## 使用說明

### 新增知識項目
1. 點擊「新增項目」按鈕
2. 填寫標題、內容、標籤、分類和備註
3. 點擊「儲存」保存

### 匯入檔案
1. 點擊「點擊選擇檔案」按鈕
2. 選擇 PDF、.md/.markdown、圖片、影片或文檔檔案
3. 系統會自動解析並建立知識項目

### 搜尋與篩選
- 使用搜尋框輸入關鍵字進行全文搜尋（搜尋標題、內容和備註）
- 點擊標籤按鈕進行標籤篩選
- 使用分類下拉選單進行分類篩選
- 點擊「清除全部」移除所有搜尋和篩選
- 排序支援：最後更新、建立時間、標題（升冪/降冪）

### 檢視模式
- **圖示檢視**：以卡片式佈局顯示縮圖
- **並排檢視**：列表式佈局，左圖右文
- **詳細資料檢視**：完整內容預覽，包含備註顯示

### 標籤管理
- 點擊標籤旁的編輯圖示重新命名標籤
- 使用合併功能將多個標籤合併為一個
- 刪除標籤會從所有項目中移除該標籤

### 分類管理
- 在編輯項目時為其分配分類
- 重新命名或刪除分類（不會刪除項目本身）

### 自動分類
- 點擊「為所有項目自動分類」按鈕
- 系統依據預定義的關鍵字規則自動添加標籤
- 支援技術、學習、工作、生活、參考、重要、待辦等分類

### 資料匯出/匯入
- **匯出**：將所有知識項目匯出為 JSON 檔案
- **匯入**：支援合併模式（新增項目）或替換模式（取代所有資料）

### PDF 檢視
- 點擊 PDF 項目開啟內建 PDF 檢視器
- 支援多頁 PDF 切換
- 可最大化或下載原始 PDF

### 影片播放
- 點擊影片項目開啟內建影片播放器
- 支援原生 HTML5 影片控制

### 文檔檔案
- 文檔檔案顯示檔案圖示
- 點擊可下載原始文檔檔案
- 系統會自動提取文字內容以供搜尋
